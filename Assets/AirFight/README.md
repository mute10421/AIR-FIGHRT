# Air Fight — Galaxy XR 1인칭 전투기 (Unity 6 / Android XR)

F-16C를 모델로 한 VR 공중전 게임. 외부 에셋 없이 모든 기체·조종석·지형·사운드를 코드로 생성합니다.

## 처음 설정 (한 번만)

1. Unity에서 프로젝트를 열면 `Packages/manifest.json`에 추가된 XR 패키지(OpenXR, Android XR, XR Management, **XR Hands**)가 자동 설치됩니다.
2. 메뉴 **Air Fight → Setup Everything** 실행 → 머티리얼, `Assets/AirFight/Scenes/AirFight.unity` 씬, Android 플레이어 설정(IL2CPP·ARM64·Vulkan)이 만들어집니다.
3. **Edit → Project Settings → XR Plug-in Management**
   - Android 탭: **OpenXR** 체크 → **Android XR** 기능 그룹 체크
   - OpenXR(Android 탭) 기능 목록에서 **Hand Tracking Subsystem** 체크 ← 맨손 조종에 필수
   - **Project Validation → Fix All**
4. **File → Build Profiles → Android** 로 전환 → Galaxy XR 연결(개발자 모드) → **Build And Run**
5. 첫 실행 때 **손 추적 권한**을 허용 (권한은 빌드 시 자동으로 매니페스트에 추가됨)

에디터에서 ▶ Play를 누르면 헤드셋 없이도 키보드/게임패드로 비행 테스트가 됩니다.

## 시작 메뉴 (모드 선택)
▶ Play 하면 활주로 위 기체를 3인칭으로 보여주는 **시작 메뉴**가 뜹니다. 검지로 누르기(VR) · 마우스 클릭 · 키보드로 고릅니다.

| 모드 | 내용 | 키 |
|---|---|---|
| **AI BATTLE (AI 대전)** | 난이도 EASY / NORMAL / ACE, 출발 RUNWAY(이륙 후 고도 300 m에서 적 출현) / AIR START(고도 3000 m에서 바로 교전) 선택 후 LAUNCH | 1 → (1·2·3 난이도, R/A 출발, Enter) |
| **FREE FLIGHT (자유 비행)** | 적 없이 비행 · 이착륙 · 보급 연습 | 2 |
| **MULTIPLAYER (멀티플레이)** | QUICK(빠른 매칭) · HOST(방 만들기) · 키패드로 코드 입력 후 JOIN. 대기실에서 방 코드와 점수판 확인 후 TAKE OFF | 3 → (F1/F2/코드+Enter) |

- 난이도: EASY = 적기 수 적고 반응 느림, 미사일 늦게 / ACE = 적기 많고 1웨이브부터 미사일, 사격 정밀
- 비행 중 **Esc** 또는 조종석 오른쪽 벽 **MENU** 버튼 → 메뉴로 돌아감 (멀티플레이 중이면 방에서 나감)
- 비행 중 P / MULTI 버튼의 멀티 패널도 그대로 사용 가능

## 맨손 조종 (컨트롤러 없음)

의자에 앉아 실제 F-16 조종석처럼 손을 둡니다. 게임 속 손(살색 선)이 내 손을 따라 움직이고, 무언가를 잡으면 초록색으로 바뀝니다.

**오른손 = 사이드스틱 (오른쪽 허벅지 옆 콘솔)**

| 동작 | 손 동작 |
|---|---|
| 스틱 잡기 | 스틱 위에서 주먹 쥐기 (중지·약지·새끼). **엄지는 세워서 스틱 위에 올려두기** |
| 피치 / 롤 | 잡은 채 손을 앞뒤 / 좌우로 약 5cm 이동 (앞 = 기수 내림, 뒤 = 기수 올림) |
| 러더 | 잡은 채 손목을 좌우로 비틀기 |
| 기관포 | 검지를 당기기 (손이 주황색으로 변함) |
| 미사일 발사 (피클) | 세워둔 엄지를 검지 옆으로 꾹 누르기 |
| 놓기 | 손 펴기 → 스틱은 스프링처럼 중립 복귀 |

**왼손 = 스로틀 (왼쪽 콘솔)**

| 동작 | 손 동작 |
|---|---|
| 스로틀 잡기 | 손잡이 위에서 주먹 쥐기 |
| 추력 | 앞으로 밀기 = 증가. MIL에서 한 번 걸리고, 1.5cm 더 밀면 애프터버너 |
| 스피드 브레이크 | 잡은 채 엄지를 검지 옆으로 누르고 있기 |

**조종석 버튼 = 검지 끝으로 누르기**

- 정면 패널(글레어실드 아래): **A-A GUN**, **A-A MSL**(무장 선택), **MASTER ARM**(무장 안전/활성), **RECENTER**(시점 재정렬), **RESTART**(격추 후 재시작)
- 왼쪽 벽(스로틀 옆): **GEAR**(랜딩기어), **FLARE**
- 오른쪽 벽: **VIEW** (1인칭 조종석 ↔ 3인칭 추적 시점)

3인칭에서도 손은 조종석에 앉아 있는 것과 똑같은 위치에서 스틱·스로틀·버튼을 조작합니다(보이지 않아도 손이 기억하는 자리). VR에서는 멀미 방지를 위해 3인칭 카메라가 수평을 유지하고 방향만 따라갑니다.

키보드(에디터 테스트): W 기수 올림 / S 기수 내림, A/D 롤, Q/E 러더, Shift/Ctrl 스로틀, **Space 미사일 발사**(락온되어 있으면 유도, 락온음 = 높은 삐— 소리), 마우스 왼쪽/J 기관포, Tab 무장 전환, F 미사일(Space와 같음), C 플레어, B 스피드 브레이크(지상에서는 휠 브레이크), G 기어, L 자동 착륙, V 시점(1인칭/3인칭), M 지도, P 멀티플레이, R 즉시 부활. USB/블루투스 조이스틱·게임패드도 인식됩니다.

## 이륙 (활주로 출발)

게임은 활주로 36 끝에서 엔진 아이들·주차 브레이크 상태로 시작합니다. 적은 이륙해서 고도 300m를 넘으면 나타납니다.

1. 스로틀을 앞으로 밀면 주차 브레이크가 풀리고 활주 시작 (MIL 또는 애프터버너)
2. 방향 유지: 러더(오른손 손목 비틀기 / Q·E)로 노즈휠 조향
3. 약 150~170노트에서 스틱을 당겨(키보드 W) 기수를 10~12° 들기 → 이륙
4. 이륙 후 **GEAR** 버튼(왼쪽 벽, FLARE 위)으로 기어 올리기 (키보드 G)
5. 착륙은 기어를 내리고(초록 램프) 침하율 약 1300 fpm(6.5 m/s) 이하로 접지. 지상에서 스피드 브레이크(왼손 엄지 / B)가 휠 브레이크로도 작동

## 멀티플레이 (인터넷 PvP)

**P** 키(또는 조종석 오른쪽 벽 **MULTI** 버튼)로 멀티 메뉴를 엽니다.
- **QUICK** (F1): 열린 방에 자동 참가, 없으면 새로 만듦
- **HOST** (F2): 새 방을 만들고 6자리 **방 코드**를 친구에게 알려줌
- **JOIN**: 방 코드 입력(키보드 타이핑 / VR 키패드) 후 Enter
- **LEAVE** (F3): 나가기 → 싱글플레이 웨이브로 복귀
- 최대 8명, 서로 다른 공항에서 출발. 기관포·미사일·플레어 모두 동기화(상대 미사일이 나를 쫓으면 MISSILE 경보, 플레어로 기만 가능)
- 격추하면 "PILOT 2 SPLASHED PILOT 3" 알림, 오른쪽 MFD에 킬/데스 점수판. 상대 기체 위에 P번호 표시

**처음 한 번 설정 (Unity Cloud, 무료)**
1. Unity 에디터 **Edit → Project Settings → Services** 에서 Unity 계정으로 로그인 후 **Link to Unity Cloud project** (새 프로젝트 만들기)
2. 브라우저 [Unity Cloud 대시보드](https://cloud.unity.com) → 해당 프로젝트 → **Multiplayer → Relay** 와 **Lobby** 사용 시작(Get started)
3. 같은 빌드를 Galaxy XR과 PC에서 실행해 한쪽이 HOST, 다른 쪽이 코드로 JOIN
- 같은 PC에서 에디터 두 개로 테스트할 땐 Unity의 **Multiplayer Play Mode** 패키지를 쓰면 편합니다

## 부활

격추되면 3초 뒤 (또는 R / RESTART 버튼으로 즉시) 가장 가까운 공항 활주로에서 무장을 채우고 바로 부활합니다. 맵을 다시 만들지 않아 기다림이 없습니다.

## 지도 (M)

**M** 키(또는 조종석 오른쪽 벽 **MAP** 버튼)로 전술 지도를 엽니다. 지도가 열려 있는 동안 게임이 일시정지됩니다.
- 공항 선택: 1~9 / ←→ (VR: < PREV · NEXT > 버튼)
- **RUNWAY** (T/Enter): 선택한 공항 활주로로 순간이동 (이륙 대기)
- **FINAL** (F): 10km 최종 접근 경로로 순간이동 (착륙 연습)
- **NAV** (N): HUD에 길 안내 (방위 테이프 파란 마커 + 공항 위 파란 다이아몬드 + 거리)
- 닫기: M / Esc / CLOSE

## 그래픽

에셋 없이 코드로 만든 사실적 연출: HDR + ACES 톤매핑 + 블룸 + 색보정, MSAA 4x, 대기 산란 하늘과 하늘 기반 환경광, 부드러운 반투명 적운(빌보드), GPU 인스턴싱 침엽수 숲(최대 6만 그루), 1536px 지형 텍스처 + 지형 음영, 광택 바다, 금속/무광 PBR 기체 도장과 금빛 캐노피, 발광 활주로 등·PAPI, 애프터버너/폭발 HDR 발광, 고G 날개끝 베이퍼. Galaxy XR(모바일)에서는 해상도·숲 밀도·블룸을 자동으로 낮춤.

## 연료 & 보급

내부 연료 3,200kg. 아이들 0.12kg/s, MIL 약 1.4kg/s, 풀 애프터버너 약 7kg/s (애프터버너만 쓰면 약 7분). 연료가 줄면 기체도 가벼워집니다.
600kg 아래 **BINGO FUEL** 경고, 0이 되면 엔진이 꺼지고(FLAMEOUT) 활공만 가능.
**아무 공항에나 착륙해 완전히 멈추면** 2초 뒤 기관포 511발·AIM-9 4발·플레어·수리가 즉시, 연료는 약 10초에 걸쳐 가득 채워집니다.

## 공항 & 착륙

섬에 공항 9곳: **SOUTH AB**(출발 기지, RWY 36), **EAST**, **NORTH**, **WEST**, **CENTRAL**, **NE**, **SE**, **SW**, **NW AB**. 레이더 MFD에 초록 활주로 기호로 표시됩니다. 모든 활주로 양쪽 끝 10 km 진입로는 산을 깎아 3° 강하 경로가 항상 비어 있습니다.
어느 공항이든 착륙해서 완전히 멈추면 2초 뒤 **무장·플레어 재장전 + 수리**.

착륙 돕기:
- **자동 착륙 (L 키 / 게임패드 십자키↑ / 조종석 왼쪽 벽 AUTOLAND 버튼)**: **어디서 켜도** 무조건 활주로 위로 내림. 목표 = 지도(M)에서 NAV로 고른 공항, 없으면 가장 가까운 공항. 오토파일럿이 경로·고도·속도·엔진 추력을 전부 자동으로 조절
  1. NAV — 활주로 연장선 5 km 진입점까지 약 470 kt로 빠르게 비행, 엔진 추력·스피드브레이크 자동 (고도 300 m 이상·지형 회피, 너무 높으면 바깥으로 돌며 강하)
  2. FINAL — 기어/플랩 자동 내림, 활주로 중심선 + 3° 강하 경로를 정확히 따라감, 약 150 kt로 감속
  3. FLARE → 접지 → 스피드브레이크 + 최대 제동으로 정지 → 주차 브레이크 (LANDED)
  - **땅 위에서 누르면 자동 지상 주행**: 가장 가까운 활주로 끝까지 스스로 달려가서 중심선에 정렬하고 멈춤 → 스로틀 올리면 바로 이륙
  - 스틱을 크게 움직이면 즉시 해제, 다시 누르면 끔
- **사격·추적 보정 (약하게)**: 적기가 기수 앞 ±20°·4 km 안에 들어오면 기수를 사격 리드 지점 쪽으로 살짝 돌려 줌(최대 5°/s, 스틱을 반대로 크게 밀면 약해짐). 기관포 탄은 리드 지점 쪽으로 최대 2.5° 휘어지고, 적기 6 m 이내를 지나가면 명중 처리
- **레이더 경보 (RWR)**: 적이 나를 추적하면 HUD "SPIKE — TRACKED" + 느린 삑삑음, **미사일 락온**하면 "LOCK" 깜빡임 + 빠르고 높은 경고음, 미사일 발사되면 "MISSILE" + 교대 경보음. AI 적기와 멀티플레이 상대 모두 적용
- **기어를 내리면 HUD에 착륙 유도 표시**: 가장 가까운 활주로 윤곽선(겹쳐 보임), 로컬라이저(세로 바늘 → 좌우 정렬)·글라이드슬로프(가로 바늘 → 3° 강하각) 바늘, 남은 거리, AoA 인덱서
  - 바늘이 십자 가운데 오도록 조종: 세로 바늘이 왼쪽이면 왼쪽으로, 가로 바늘이 아래면 기수를 내림
  - 받음각 13° 유지 (HUD에 `ON SPEED (o)` / `FAST (v)` / `SLOW (^)`) ≈ 150노트
- **PAPI 등** (활주로 왼쪽 빨강/흰색 4개): 흰2·빨2 = 정상 경로, 흰색 많으면 높음, 빨강 많으면 낮음
- **지면 효과**: 지면 12m 이내에서 양력 증가 → 자연스러운 쿠션
- 3° 강하 그대로 접지해도 약 800 fpm이라 문제없음. 1400 fpm 이상은 데미지(HARD LANDING), 2750 fpm 이상이면 기어 파손

## 비행 모델 (FlightModel.cs)

- **움직이는 조종면**: 스태빌레이터(피치·롤), 플래퍼론(롤 + 기어 내리면 20° 플랩), 앞전 플랩(플랩 + 받음각에 따라 처짐), 스피드 브레이크 판(55° 열림)이 실제 작동기 속도로 움직임 — 조종석에서 고개를 돌리거나 3인칭(V)에서 보임
- **브레이크**: 휠 브레이크 마찰 0.85(안티스키드), 지상에서 스피드 브레이크를 펴면 양력 덤프로 바퀴에 하중이 실려 더 잘 섬. 공중 스피드 브레이크 항력도 강화

- 양력·항력·측력: 받음각, 동압, 고도별 공기밀도, 천음속 조파항력 반영 → 9G 선회 시 속도가 급격히 떨어짐
- F110 엔진: MIL 76 kN / AB 129 kN, 고도에 따른 추력 감소, 엔진 스풀업 지연
- **속도에 따른 기수 조종**: 조종면 효율 = 동압(½ρV²)에 비례
  - 저속: 스틱 = 피치 레이트 명령. 기수는 들리지만 느리고 둔하며, AoA 25° 한계 때문에 G가 거의 안 나옴 (150kt에서 약 1.4G)
  - 코너 속도(약 450kt): 가장 빠른 선회 — 약 22°/s, 9G
  - 고속(550kt 이상): 같은 스틱이 9G 한계에 걸려 기수 회전이 오히려 느려짐 (600kt 약 15°/s, 780kt 약 11°/s)
  - 스틱을 놓으면 1G 유지, 롤 레이트 최대 240°/s (저속에서 감소)
- **지상**: 앞바퀴는 약 100kt부터 들리기 시작하고 140~150kt에서 쉽게 회전. 기어를 내리면 플랩이 자동으로 내려가 약 160kt에서 이륙
- 코너 속도 약 450 KCAS, 최고 속도 고고도 약 마하 1.8

## HUD / 계기

30m 앞에 배치된 HUD로 실제 HUD처럼 무한원에 시준된 효과(머리를 움직여도 심볼이 바깥 풍경에 고정): 피치 래더, 속도벡터(FPM), 속도(KCAS)/고도(ft)/레이더 고도, 방위 테이프, G·마하·AoA, 표적 지시 박스, 기관포 리드 서클, AIM-9 시커 서클(탐색 그롤 → 락 고음), PULL UP / MISSILE 경고.
좌측 MFD = 레이더(B-스코프 40km), 우측 MFD = 무장/웨이브 상태.
